# Rulings register — SEND-82 entries (2026-08-21)

## REGISTERED: THE CONTROL-TESTING STANDARD (Howard, send-82)
"A PROPOSED PROPERTY IS TESTED AGAINST THE CASES IT WAS NOT INVENTED
FOR, NOT ONLY THE ONES IT WAS." Running SEND-81's outermost property
against the 8 currently-KEPT boundaries as controls is what killed it
before it shipped. Standard from here on: every proposed
rule/property is run against its non-target population (kept
boundaries, resolving faces, accepted joints) before any wiring, and
the control results appear in the report.

## REGISTERED: THE LEFT-32.60 CANCELLATION (send-82 item 2)
Letrick left's 32.60 today rests on TWO independent coincidences:
(1) the read carries the projection on the FRONT edge via a
fragment-luck chain (x 43.22→45.30) while dropping the REAL chimney
on the BACK edge (x 17.43/17.67 — settled by Howard's prints);
(2) both candidate projections measure ≈2'-7", so 30' + one
projection is ≈32.6 ft WHICHEVER edge carries it. THE WIDTH IS RIGHT
AND THE SHAPE IS WRONG. The next reader of 32.60 must know what it
rests on. Under propose-and-correct the acceptance is THE SHAPE, not
the number: a left that reads 32.60 with the bump on the front edge
is a FAILURE.

## REGISTERED: WHAT THE DRAWING DOES NOT DISTINGUISH (send-82 item 3)
LEFT-17.67 AND RIGHT-79.77 ARE STRUCTURALLY IDENTICAL IN THE OUTLINE.
The drawing does not distinguish a chimney from a course-end line by
silhouette geometry alone. Only the SHOULDER distinguishes them, and
only on one of the two drawings. If Ruling CCC works, it works because
right happens to be drawn with a shoulder. A SET WHERE NEITHER SIDE
HAS ONE CANNOT RESOLVE EITHER PROJECTION, and the honest outcome is
INDETERMINATE on both. Do not build toward a future where every
projection is resolvable; build so that an unresolvable one says so.
