# Lesson — 2026-08-03: the blank census that swept protected fixtures
- What happened: "delete every phantom blank" was executed as a raw-Mongo delete of every estimate with 0 lines/0 openings. Four of those were PROTECTED SEED FIXTURES (run anchors: Letrick 8f95c9c2, red-house 673707d5, haugh-validation 48231310, round-two d78cd3b4). 79 suite failures followed; restored via `python seed/seed_runner.py apply` (INSERT-ONLY, verbatim) + re-slotting 2 test-slot company ids.
- Why it happened: census projection didn't fetch `protected`; delete went around the API guard (DELETE /estimates/{id} answers 423 "Protected fixture").
- Rules going forward:
  1. NEVER raw-delete estimates. Use the API delete — it enforces the protection guard.
  2. Before any purge: check `protected`, `fixture_import`, backend/fixtures/manifest.json, and grep tests/ for the ids.
  3. "Blank" ≠ phantom. Run-anchor fixtures carry 0 lines by design.
  4. The suite is a reader too — Howard's "does anything read this?" check must include tests and the seed manifest.
