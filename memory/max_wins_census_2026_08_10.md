## NAMED RELATIVES (max over readings — reviewed, unchanged per order)
3. **Box-model rect** (readback wing check): rect = max(front, back) ×
   max(left, right). Opposing walls SHOULD be equal; when reads differ,
   the larger pair inflates the rect — which SUPPRESSES wing_flag
   (fires only when footprint > rect × 1.02). A masking max on an
   instrument, not an order quantity. Candidate if ruled: use the
   average, or flag when opposing walls disagree beyond tolerance.
4. **Porch wall-side pick** (`sum(max(w, l))`, hover soffit-J split):
   the LONGER porch dim is assumed wall-abutting. One read, two dims —
   an orientation ASSUMPTION, not a race. Wrong on a porch deeper than
   wide (over-counts the ceiling-receiving J, under-counts the wall J).
5. **Gable ridge cross-check** (gableMath.js): compares the LARGEST
   implied rise per elevation. Comparison instrument only (a warning);
   feeds no quantity. Inert.

   dormer_face_sqft becomes THE dormer face for the 3D panel; contractor
   can override. Display/3D only; the sqft itself rides profile math
